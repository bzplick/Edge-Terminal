# Edge Terminal

Mobile-first trading scanner dashboard combining three systems:

1. **Don't Dilute Me** — quality reversal swings with lower dilution risk.
2. **Panic Reversal Scanner** — capitulation bounce setups with volume returning.
3. **Early Explosion Scanner** — quiet accumulation before breakout attempts.

This repo currently includes a working static `index.html` prototype and a full `CODEX_PROMPT.md` for Codex to build the cleaner production version with React/Vite + FastAPI + Railway deployment.

## Quick Start

Open `index.html` in a browser.

The first version uses demo data so the UI works immediately without paid API keys.
